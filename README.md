# Sasidhar Mukthinuthalapati — portfolio

Personal site for a Senior Data Engineer / Tech Lead. Static HTML, CSS, and JavaScript. Ready for GitHub Pages.

## Run locally

From this folder:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Contact form

The page does not show an email or phone number. Messages go through [Formspree](https://formspree.io) to your inbox.

1. Create a free form at Formspree and confirm the destination email there (not on this site).
2. Copy the form ID and replace `YOUR_FORM_ID` in `index.html` (`action="https://formspree.io/f/YOUR_FORM_ID"`).

## Publish later

This repo has no GitHub remote yet. When you are ready, push it to `Sasidhar007.github.io` (that repo already exists) and enable GitHub Pages from the `main` branch. The live URL will be `https://sasidhar007.github.io`.
